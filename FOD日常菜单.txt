日常方案二
    |主界面----------------------------------------------------------
    日期-时间                                                   星期-天气
    |                                                                   |
    |                                                                   |
    |                                                                   |
    |                       主界面内容                                   |
    |            大地区背景+角色立绘+选择对象立绘                          |
    |                                                                   |
    |                                                                   |
    |   文字独占，包含应有的各种信息                                      |
    |菜单-------------------------------------------------------------
    |ex扩展
关于主界面等等的内容，为每个大地图（也就是区域）定义一个背景图片，然后把背景图片放上去，然后把角色立绘通过偏移调整方式放上去
包括说地图的天气变化腐化变化可以通过类似角色气泡这种东西通过偏移调整加上去
