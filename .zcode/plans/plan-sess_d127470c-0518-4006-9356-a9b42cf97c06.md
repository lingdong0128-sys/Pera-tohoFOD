## 二、dynamic_loader.py（主战场）

### 1. `__init__` 状态替换
删：`scroll_offset`、`current_display`、`clickable_regions`、`active_clickable_regions`、`clickable_region_counter`、`max_visible_items`、`text_surface_cache`（后两个是确认过的死变量）。
增（盒子三量 + 缓存）：
```python
self.tail_gap = 0            # 盒底之下的流项数；0=在流尾（追更）
self.box_dirty = True        # 三时机才重排：流追加且在流尾 / 盒子移动 / 容量变化
self.new_content_below = False
self.box_items = []          # [(预渲染surface, y)]，重排时生成
self.box_hit_rects = []      # [(rect, click_value)]，重排时一次算好
```

### 2. 新增 `_compose_box()`（替代 `_update_current_display`）
- 盒底锚定：`bottom_idx = len(history)-1-tail_gap`，向 older 方向**贪心装填**至 `content_area_height`；
- 装不下且盒非空 → break：该项属于更老的盒位（"图片装不下整体等下一盒"由此天然成立，图片项高度整体计、永不切分）；
- 单项高超整盒 → 钳制到盒高；
- **重排时预渲染每项 surface**（文本项：fragment 逐个 font.render/blit 到透明条；图片项：现有裁剪/缩放管线跑一次；立绘叠加：合成一次）——draw() 从此零 font.render、零 smoothscale；
- **重排时一次算命中矩形**：文本项按 fragment x 累计（宽度 add 时已存）、图片项整块——双簿记注册表整个退役。

### 3. 各 `add_*` 尾部两行改写
`_update_current_display()` + `scroll_offset<=5 自动滚` →
```python
if self.tail_gap == 0: self.box_dirty = True
else: self.new_content_below = True
```
同时删除三处向注册表登记点击区域的代码块。

### 4. 滚动 API（外部名不变，内部 tail_gap）
- `scroll_up/down(n)`：tail_gap ±n，钳位 [0, len-1]，置脏；回到 0 时清 new_content_below；
- `scroll_to_bottom/top`：tail_gap=0 / max；
- `handle_event` 键位保持（滚轮3、方向键1、Home/End），**PgUp/PgDn 从 10 行改为整盒行数**（capacity//line_height）——落实规格。

### 5. `draw()` 重写
盒脏才 compose；否则纯 blit `box_items` + 滚动条（tail_gap 算术）+ 回看时右下"↓ 有新内容"提示。删除每帧 `_update_active_clickable_regions()` 调用与 `'id':-1` 野区域追加。

### 6. 其余
- `handle_mouse_click` → 查 `box_hit_rects`（SCALED 已把鼠标换算成设计坐标）；
- `get_scroll_info` 字段兼容改算；
- `clear_history` 重置盒状态；`set_font` 置盒脏；
- 删 `_update_active_clickable_regions`、`clear_clickable_regions`、`_update_current_display`。

## 风险与边界
- item.height 为 add 时记录：set_font 后旧项行高陈旧——既有行为，不扩大范围；
- set_font 与盒缓存：置脏即可，重排会用新字体渲染旧文本（比现状更好）；
- 内存：一盒预渲染 surface ≈ 50条×1600×24px，可忽略；history 10000 上限与截断语义不变（tail_gap 是尾部相对量，截断无需修正）。
