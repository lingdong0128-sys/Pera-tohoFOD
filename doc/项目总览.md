## 一、这是什么项目

**Pera东方FOD** 是一个基于 **Pera 框架**（Python + Pygame 实现的 ERA 游戏前端）开发的**东方 Project 二创肉鸽地牢探险黄油**。

- 框架：Pera（本仓库自带，参考 [doc/readme.md](./readme.md)，外部文档 https://deepwiki.com/py-era/Pyera ）
- 语言/运行时：Python 3.13.x + Pygame 2.6.1
- 剧情背景：欲望之神在幻想乡释放欲望，形成不断蚕食幻想乡的地牢；玩家作为隐士，在 5 年期限内与其他角色一起探索地牢、收集线索，阻止幻想乡被吞噬。剧情全文见 [Pera幻想FOD剧情设计.txt](../Pera幻想FOD剧情设计.txt)
- 设计日志（按日期记录的开发思路，最重要的设计来源）：[Pera幻想FOD设计思路.txt](../Pera幻想FOD设计思路.txt)

### 核心玩法设计

| 设计点 | 说明 |
|---|---|
| 腐化吞并 | 大地图区块随主线推进逐渐被并入地牢区块（map.json 中每个区域有"腐化"键） |
| 肉鸽地牢 | 进入地牢时随机生成房间网图（dict，房间记录 exits 指向相邻房间 ID），房间类型来自 DungeonRooms.csv |
| 时间即资源 | 移动/行动消耗基础时间单位（分），通过"时间管理器"统一结算；主角睡觉时其他角色也在行动 |
| 花销 AI | 每个角色按"花销(Cost)"决定行为，选 Cost 最小的行动执行，实现 NPC 自主活动 |
| 珠(Palam/Juel)系统 | ERA 风格的好感/快感底层单位，等级翻倍增长，5 级高潮清空并计数 |
| 主线压力 | 主线时间线随游玩天数自动推进，不推动主线也会变坏 |

## 二、快速上手

```shell
# 环境：Python 3.13.x
pip install -r requirements.txt
python main.py
```

- 主菜单输入 `0` 进入 start（新游戏流程），`10` 加载存档，`kojo_maker` 打开口上制作器，`debug` 查看状态。
- 打包：仓库根目录有 `Pera_Game.spec`（PyInstaller），`Pera_Game.exe` / `dist/` / `build/` / `_internal/` 为旧打包产物。
- 每次运行的事件加载日志会打印在控制台；游戏内报错会以红色 PRINT 输出。

## 三、技术架构

### 核心模块（仓库根目录）

| 文件 | 职责 |
|---|---|
| `main.py` | 入口。`thethings` 类就是游戏主对象（事件里的 `this`），持有 console / event_manager / charater_pwds / cs，跑主菜单循环 |
| `ERAconsole.py` | `SimpleERAConsole`：Pygame 控制台，提供 `PRINT` / `INPUT` / `PRINTIMG`；`allstate`（运行时总状态）挂在它身上；`init_all()` 完成初始化 |
| `Eventmanger.py` | `EventManager`：递归扫描 `events/` 动态导入，所有 `event_` 开头的函数注册为事件；`trigger_event(名, this, *args, **kwargs)` 触发（支持 `silent=True`）；记录调用栈供存档 |
| `init.py` | `initall`：读取 `csv/characters/`（角色数据）与 `csv/global/`（全局变量），按关键词（基础/素质/能力/CFLAG/相性/CSTR）分类进 `charaters_key` / `global_key` |
| `dynamic_loader.py` | 渲染引擎：行内片段（InlineFragment）、滚动、图片叠加渲染等 |
| `clickable.py` | `ClickableString`：带颜色/点击回调的文本对象（`cs()` 快捷函数） |
| `utils/era_handler.py` | `EraKojoHandler`：模拟 ERB 变量操作的适配层（ERA 迁移/口上调用用） |
| `utils/save.py` | 存档读写 |
| `Musicbox.py` | 音乐播放 |

### 事件系统规约（写事件必读）

- `events/` 下任意 `.py` 文件中，函数名以 `event_` 开头即自动注册为事件，事件名 = 去掉前缀后的部分（支持中文事件名）。
- 事件第一个参数固定是 `this`（即 `main.py` 的 `thethings` 实例）：
  ```python
  def event_我的事件(this, 其他参数...):
      this.console.PRINT("你好")           # 输出
      x = this.console.INPUT()             # 输入
      this.event_manager.trigger_event('其他事件', this, 参数)  # 触发事件
  ```
- 在函数定义后设置 `event_我的事件.is_main_event = True` 可将其标记为**主事件**（存档只记录主事件栈，读档回到最近的主事件）。
- `trigger_event(..., silent=True)`：事件不存在或报错时不向玩家打印信息（口上调用常用）。
- `events/重载事件.py` 提供热重载（清理 `sys.modules` 缓存后重新加载）。
- 全部事件约 148 个（`grep -rn "def event_" events | wc -l`）。

### 数据存放

| 位置 | 内容 |
|---|---|
| `csv/characters/<角色ID>/Chara<ID> <名前>.csv` | 每个角色一个文件夹（东方全角色，ID 0~1xx） |
| `csv/global/*.csv` | 全局变量：ERA 系（Abl/Base/CFLAG/Talent/Palam/Juel/Item…）+ 本作新增（怪物/技能/异常状态/角色地牢属性/DungeonRooms/time/map/musicbox…） |
| `json/map/map.json` | 地图数据（大地图→小地图，含"腐化"状态键） |
| `json/map/flag.json` | 工作流 flag（`good_work` 表示上一轮工作流验收通过） |
| `img/` `font/` `Musicbox/` | 立绘、字体（luoli.ttf）、音频 |
| `save/` | 存档 JSON |

## 五、游戏主流程（当前实现）

```
main.py 主菜单
  └─ [0]start → events/start.py
       ├─ init_data_adapters / init_race_data / custom_chara_init
       ├─ time_control('init')  + 天气初始化（默认'晴'）
       ├─ 立绘检查（设置立绘类型选择 / 跳过）
       └─ while 循环：get_context_state 取 session.scene_type 分流
            ├─ '日常' → handle_daily_routine
            │     · 每帧重取 ctx 快照
            │     · 检测当前大地图"腐化"→ 自动切入地牢（SCENE='地牢'）
            │     · UI（彩色进度条）/立绘/状态栏/地图移动/聊天/商店
            └─ '地牢' → handle_dungeon_crawling
                  · 房间事件触发时传 room_data
                  · 战斗房间 → 进入房间_遇敌 → 怪物特点判定（善良/邪恶/伪装30%识破）
                  · 战斗胜利 50% 掉落；败北触发 H 场景（待实现）
```

启动链中还有：master 选择 → 自定义角色 → 立绘选择 → 口上选择 → 难度选择（部分已实现、部分待做，详见设计思路 [2025/12/19-23:22] 一节）。
