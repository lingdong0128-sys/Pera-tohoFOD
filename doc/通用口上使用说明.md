# 通用口上地文系统使用说明

## 概述

通用口上地文系统为游戏提供了一套默认的口上内容，当找不到特定角色的口上时会自动回退到通用口上。这样即使新添加的角色还没有写专门的口上，也能有基本的交互对话。

## 文件结构

```
events/口上/通用口上/
├── __init__.py                      # 模块初始化
├── 通用口上地文_日常系.py           # 日常场景通用口上
├── 通用口上地文_H系.py              # H场景通用口上
├── 通用口上地文_地牢系.py           # 地牢战斗通用口上
└── 口上调用助手.py                  # 统一调用接口
```

## 口上类型和接口

### 1. 日常系口上

**可用动作类型：**
- `聊天` - 普通聊天对话
- `问候` - 问候语（根据时间段不同）
- `告别` - 告别语
- `触摸` - 触摸动作
- `抱住` - 拥抱动作
- `询问` - 询问角色
- `观察` - 观察角色
- `邀请` - 邀请角色

### 2. H系口上

**可用动作类型：**
- `开始` - H开始
- `高潮` - 高潮场景
- `接吻` - 接吻场景
- `爱抚` - 爱抚场景
- `结束` - H结束

### 3. 地牢系口上

**可用动作类型：**
- `遭遇敌人` - 遭遇敌人时
- `胜利` - 战斗胜利
- `失败` - 战斗失败
- `受伤` - 受伤时
- `发现宝箱` - 发现宝箱
- `休息` - 休息时

## 调用方式

### 方式一：使用快捷事件（推荐）

直接在代码中调用具体动作的快捷事件：

```python
# 日常系
this.event_manager.trigger_event('日常_问候', this)
this.event_manager.trigger_event('日常_告别', this)
this.event_manager.trigger_event('日常_触摸', this)
this.event_manager.trigger_event('日常_抱住', this)
this.event_manager.trigger_event('日常_询问', this)
this.event_manager.trigger_event('日常_观察', this)
this.event_manager.trigger_event('日常_邀请', this)

# H系
this.event_manager.trigger_event('H_开始', this)
this.event_manager.trigger_event('H_高潮', this)
this.event_manager.trigger_event('H_接吻', this)
this.event_manager.trigger_event('H_爱抚', this)
this.event_manager.trigger_event('H_结束', this)

# 地牢系
this.event_manager.trigger_event('地牢_遭遇敌人', this)
this.event_manager.trigger_event('地牢_胜利', this)
this.event_manager.trigger_event('地牢_失败', this)
this.event_manager.trigger_event('地牢_受伤', this)
this.event_manager.trigger_event('地牢_发现宝箱', this)
this.event_manager.trigger_event('地牢_休息', this)
```

### 方式二：使用统一入口

通过统一入口调用，需要指定动作类型：

```python
# 日常系
this.event_manager.trigger_event('通用口上_日常', this, '聊天', '1')
this.event_manager.trigger_event('通用口上_日常', this, '问候', '1')

# H系
this.event_manager.trigger_event('通用口上_H', this, '开始', '1')
this.event_manager.trigger_event('通用口上_H', this, '高潮', '1')

# 地牢系
this.event_manager.trigger_event('通用口上_地牢', this, '胜利', '1')
this.event_manager.trigger_event('通用口上_地牢', this, '受伤', '1')
```

参数说明：
- 第二个参数：动作类型（字符串）
- 第三个参数：目标角色ID（可选，默认为当前选择对象）

### 方式三：使用底层函数（高级用法）

在自定义事件中直接使用底层调用函数：

```python
from events.口上.通用口上.口上调用助手 import call_daily_kojo

# 构建口上上下文
state = this.event_manager.trigger_event('get_context_state', this)
kojo_context = {
    'TARGET': target_id,
    'PLAYER': state['session'].get('master_id', '0'),
    # ... 其他上下文参数
}

# 调用口上（自动回退）
call_daily_kojo(this, '聊天', target_id, this.event_manager, this.console)
```

## 回退机制

系统会按照以下优先级查找口上：

1. 首先尝试调用特定角色的口上：`{角色ID}_{口上类型}_{系别}_{动作}`
2. 如果找不到，自动回退到通用口上：`common_{系别}_{动作}`

例如：
- 尝试调用：`1_初期口上_日常_聊天`
- 如果失败，回退到：`common_日常_聊天`

## 自定义通用口上

### 修改通用口上内容

直接编辑对应的通用口上文件：

```python
# 编辑 events/口上/通用口上/通用口上地文_日常系.py

def event_common_日常_聊天(this):
    """通用日常聊天口上"""
    context = getattr(this, 'current_kojo_context', {})
    kojo = EraKojoHandler(this.console, context)
    
    # 修改这里的对话内容
    this.console.PRINT(f"{kojo.CALLNAME}：「这里写你的通用对话」", colors=(255, 255, 255))
    this.console.INPUT()

event_common_日常_聊天.event_trigger = 'common_日常_聊天'
```

### 添加新的通用口上接口

1. 在对应的通用口上文件中添加新的事件函数
2. 添加 `event_trigger` 属性
3. 在 `口上调用助手.py` 中添加对应的调用函数和快捷事件

例如添加"拥抱"口上：

```python
# 在 通用口上地文_日常系.py 中添加
def event_common_日常_拥抱(this):
    """通用拥抱口上"""
    context = getattr(this, 'current_kojo_context', {})
    kojo = EraKojoHandler(this.console, context)
    
    this.console.PRINT(f"{kojo.CALLNAME}：「{master_name}...」", colors=(255, 255, 255))
    this.console.INPUT()

event_common_日常_拥抱.event_trigger = 'common_日常_拥抱'

# 在 口上调用助手.py 中添加
def event_日常_拥抱(this, target_id=None):
    """日常拥抱快捷调用"""
    this.event_manager.trigger_event('通用口上_日常', this, '拥抱', target_id)
event_日常_拥抱.event_trigger = '日常_拥抱'
```

## 通用口上中的变量

在通用口上中可以访问以下常用变量：

```python
# 通过 EraKojoHandler 访问
kojo = EraKojoHandler(this.console, context)

# 基础信息
master_name = this.console.init.charaters_key.get(kojo.MASTER, {}).get('全名', '你')
target_name = kojo.NAME
call_name = kojo.CALLNAME

# 角色属性
favor = kojo.CFLAG.get('好感度', 0)
love = kojo.CFLAG.get('爱意', 0)
hp = kojo.BASE.get('体力', 0)

# 环境信息
time_of_day = context.get('TIME', '昼')  # 早晨/昼/夜
weather = context.get('WEATHER', '晴')     # 晴/雨/雪等
```

## 示例：在菜单中添加口上调用

```python
def event_示例_菜单(this):
    """示例：在菜单选项中调用口上"""
    this.console.PRINT("请选择动作：")
    this.console.PRINT("1. 问候")
    this.console.PRINT("2. 触摸")
    this.console.PRINT("3. 邀请")
    
    choice = this.console.INPUT_INT()
    
    if choice == 1:
        this.event_manager.trigger_event('日常_问候', this)
    elif choice == 2:
        this.event_manager.trigger_event('日常_触摸', this)
    elif choice == 3:
        this.event_manager.trigger_event('日常_邀请', this)
```

## 注意事项

1. **事件触发器命名**：每个口上函数都需要设置 `event_trigger` 属性，这是系统识别事件的唯一标识
2. **上下文管理**：每次调用口上前后会自动设置和清理 `current_kojo_context`
3. **ID格式**：角色ID应为字符串类型
4. **回退日志**：当回退到通用口上时，会输出调试信息（灰色文字，静默模式）

## 扩展建议

1. 可以根据角色性格添加多个通用口上模板
2. 可以根据时间、地点等条件动态选择不同的通用口上
3. 可以在特定节日添加特殊的通用口上
4. 可以扩展更多系的通用口上（如战斗系、探险系等）
