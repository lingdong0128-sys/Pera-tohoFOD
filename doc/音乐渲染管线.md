# MID 渲染管线（MusicBox 音源方案）

> 2026-09-14 建立。解决 pygame 播放 `.mid` 走 Windows GS Wavetable Synth（祖传 2MB 音色库，
> "效果是一大坨"）的问题。

## 原理

pygame.mixer 播 `.mid` 时 SDL_mixer 把合成甩给系统 MIDI 设备（Windows 上就是 GS Wavetable）。
本管线**绕开运行时合成**：开发期用 FluidSynth + SoundFont 把 mid 预渲染成 ogg 缓存，
游戏运行时 `MusicBox.load_music` 自动优先加载同名 `.ogg/.wav`——玩家零依赖、打包 exe 无顾虑、
还顺便解决了 Windows 独占的跨平台问题。

```
Musicbox/xxx.mid ──(tools/mid渲染.py: FluidSynth + SF2 → wav → ffmpeg → ogg，一次性)──▶ Musicbox/xxx.ogg
                                                                              │
游戏运行时 MusicBox.load_music("xxx.mid") ──自动解析──▶ 播放 xxx.ogg（pygame.mixer）
```

## 使用

```shell
.venv/Scripts/python tools/mid渲染.py          # 只渲染没有缓存的 mid
.venv/Scripts/python tools/mid渲染.py --force  # 全部重渲（换音色库后用这个）
.venv/Scripts/python tools/mid渲染.py --sf2 路径.sf2
```

往 `Musicbox/` 扔新 mid 后跑一次即可；`musicbox.csv` 里的路径**不用改**（仍写 .mid，
加载时自动解析）。

## 组件（均不入 git，见 .gitignore）

| 组件 | 位置 | 获取 |
|---|---|---|
| FluidSynth 2.6.0 | `tools/fluidsynth/` | [官方 Release](https://github.com/FluidSynth/fluidsynth/releases) win10-x64 包 |
| 音色库 SF2/SF3 | `tools/soundfonts/` | 推荐 [SGM-V2.01](https://archive.org/download/SGM-V2.01)（免费）；详见该目录 README |
| ffmpeg（ogg 压缩） | `.venv` 内置 | moviepy 附带的 imageio-ffmpeg，无需安装 |

## 音源选择（东方相关）

ZUN 的 MIDI 时代（红魔乡～花映冢）使用 **Roland Sound Canvas 系（SC-88Pro 为代表）**——
所谓"东方原版 MIDI 音色"指的就是它。SC-88Pro 的 SF2 转制版社区有流通（硬件 ROM 提取，
法律灰色，自行获取）；合法免费的最佳替身是 SGM-V2.01（雅马哈系风格，东方编曲社区常用）。

## 已知边界

- mid 的循环信息不会带入 ogg——循环靠 `play(loops=-1)`（music_control 已是这么做的）；
- 渲染增益固定 `-g 0.5`，整体过响/过轻可改 `tools/mid渲染.py`；
- 系统级替代方案（本机爽、不改代码）：装 VirtualMIDISynth + 音色库设为默认 MIDI 设备，
  适合自己玩，不适合随游戏分发。
