# 天气系统说明

## 概述

天气系统是Pera幻想FOD中的一个核心环境系统，通过动态天气变化影响角色的行为花销。系统根据季节和随机性生成天气，并通过修正系数影响角色的体力、精力和灵力消耗。

## 设计原理

根据Pera幻想FOD设计思路：
- 天气是影响角色花销的重要因素之一
- 天气每日更新，根据季节调整概率
- 花销会根据状态、天气、相性等因素动态变化
- 恶劣天气会增加体力消耗，降低精力消耗

## 系统架构

### 1. 天气类型

系统定义了4种基本天气类型：

| 天气 | 名称 | 体力修正 | 精力修正 | 灵力修正 | 描述 |
|------|------|----------|----------|----------|------|
| 晴 | 晴朗 | 1.0x | 1.0x | 1.0x | 天气晴朗，适合户外活动 |
| 阴 | 阴天 | 1.1x | 0.9x | 1.0x | 阴天，心情略显低落 |
| 雨 | 雨天 | 1.3x | 0.8x | 0.9x | 雨天，出行不便 |
| 雪 | 雪天 | 1.5x | 0.7x | 1.2x | 下雪，寒冷的冬日 |

### 2. 季节系统

系统实现了4个季节，不同季节有不同的天气生成概率：

| 季节 | 月份 | 晴 | 阴 | 雨 | 雪 |
|------|------|----|----|----|----|
| 春季 | 3-5月 | 50% | 30% | 20% | 0% |
| 夏季 | 6-8月 | 60% | 20% | 20% | 0% |
| 秋季 | 9-11月 | 50% | 30% | 20% | 0% |
| 冬季 | 12-2月 | 30% | 30% | 20% | 20% |

### 3. 花销修正机制

天气通过以下方式影响角色行为花销：

```
修正后花销 = 基础花销 × 天气修正系数 × 状态修正系数 × 能力修正系数
```

- **基础花销**：行为定义的默认消耗值
- **天气修正系数**：根据当前天气动态调整
- **状态修正系数**：根据角色状态（疲劳、受伤等）调整
- **能力修正系数**：根据角色能力等级调整

## 事件接口

### weather_system 事件

**Trigger ID**: `weather_system`

#### 支持的操作

##### 1. 获取当前天气

```python
result = event_manager.trigger_event('weather_system', this, 'get')
```

返回：
```python
{
    'weather': '晴',                    # 天气ID
    'name': '晴',                       # 天气名称
    'description': '天气晴朗，适合户外活动',  # 天气描述
    'stamina_modifier': 1.0,           # 体力修正系数
    'energy_modifier': 1.0,            # 精力修正系数
    'spirit_modifier': 1.0,            # 灵力修正系数
    'special_effects': []              # 特殊效果列表
}
```

##### 2. 更新天气

```python
result = event_manager.trigger_event('weather_system', this, 'update')
```

返回：
```python
{
    'success': True,
    'old_weather': '晴',                # 旧天气
    'new_weather': '阴',                # 新天气
    'weather_name': '阴',               # 天气名称
    'description': '阴天，心情略显低落',  # 天气描述
    'season': '春季'                    # 当前季节
}
```

##### 3. 获取天气修正系数

```python
result = event_manager.trigger_event('weather_system', this, 'get_modifiers', weather='雨')
```

返回：
```python
{
    'stamina_modifier': 1.3,    # 体力修正系数
    'energy_modifier': 0.8,    # 精力修正系数
    'spirit_modifier': 0.9      # 灵力修正系数
}
```

##### 4. 获取所有天气定义

```python
result = event_manager.trigger_event('weather_system', this, 'get_all_weathers')
```

返回所有天气类型的完整定义字典。

##### 5. 强制设置天气（调试用）

```python
result = event_manager.trigger_event('weather_system', this, 'set', weather='雪')
```

返回：
```python
{
    'success': True,
    'weather': '雪',
    'weather_name': '雪',
    'description': '下雪，寒冷的冬日'
}
```

## 与其他系统集成

### 1. 与花销计算器集成

花销计算器（cost_calculator）在计算行为花销时会自动调用天气系统：

```python
# events/角色AI机/cost_calculator.py
def calculate_action_cost(self, chara_id: str, action_id: str, ...):
    # ... 其他计算 ...
    
    # 应用天气修正（从天气系统事件获取）
    try:
        weather_info = self.console.event_manager.trigger_event(
            'weather_system',
            this,
            'get'
        )
        if weather_info:
            final_stamina_cost, final_energy_cost, final_spirit_cost = \
                self._apply_weather_modifiers(...)
    except Exception:
        # 如果天气系统不可用，默认使用晴天修正
        pass
```

### 2. 与每日结算集成

每日结算（daily_settlement）会调用天气系统更新天气：

```python
# events/日常相关/每日结算.py
def _update_weather(this):
    """使用天气系统事件更新天气"""
    weather_result = this.console.event_manager.trigger_event(
        'weather_system',
        this,
        'update'
    )
    if weather_result and weather_result.get('success'):
        # 记录天气变化
        this.console.PRINT(
            f"天气变化：{old} -> {new} ({name})",
            colors=(100, 200, 255)
        )
```

### 3. 与AI机集成

AI机在决策时会考虑天气对花销的影响：

- 天气通过修正系数影响各种行为的成本
- 恶劣天气下，探索、战斗等体力消耗大的行为成本更高
- 角色可能因此选择在恶劣天气时休息或进行其他行为

## 使用示例

### 示例1：获取当前天气并显示修正系数

```python
def event_show_weather(this):
    weather_info = this.event_manager.trigger_event('weather_system', this, 'get')
    
    this.console.PRINT(f"当前天气：{weather_info['name']}")
    this.console.PRINT(f"描述：{weather_info['description']}")
    this.console.PRINT(f"体力消耗修正：{weather_info['stamina_modifier']:.1f}x")
    this.console.PRINT(f"精力消耗修正：{weather_info['energy_modifier']:.1f}x")
    this.console.PRINT(f"灵力消耗修正：{weather_info['spirit_modifier']:.1f}x")
```

### 示例2：模拟天气对行为花销的影响

```python
def event_weather_cost_demo(this):
    # 测试不同天气下的探索行为花销
    test_weathers = ['晴', '阴', '雨', '雪']
    
    for weather in test_weathers:
        # 设置天气
        this.event_manager.trigger_event('weather_system', this, 'set', weather=weather)
        
        # 计算花销
        result = this.event_manager.trigger_event(
            'cost_calculator', this, 'calculate',
            chara_id='0', action_id='explore'
        )
        
        this.console.PRINT(
            f"{weather}: 体力{result['stamina_cost']} | "
            f"精力{result['energy_cost']} | "
            f"灵力{result['spirit_cost']}"
        )
```

### 示例3：天气相关事件

可以创建特殊天气事件：

```python
def event_special_weather(this):
    """特殊天气事件"""
    weather_info = this.event_manager.trigger_event('weather_system', this, 'get')
    current_weather = weather_info['weather']
    
    if current_weather == '雪':
        this.console.PRINT("大雪纷飞，或许会有什么特别的事情发生...")
        # 触发雪天特殊事件
    elif current_weather == '雨':
        this.console.PRINT("雨声淅沥，是个适合独处的好日子...")
        # 触发雨天特殊事件
```

## 扩展建议

### 1. 天气效果扩展

可以在未来添加更多天气效果：

- **特殊天气事件**：特定天气下触发特殊剧情或事件
- **天气持续时间**：天气不再每日变化，而是持续数天
- **极端天气**：添加暴风雨、大暴雪等极端天气

### 2. 影响范围扩展

天气系统可以影响更多游戏机制：

- **移动速度**：恶劣天气下移动花费更多时间
- **战斗效果**：某些天气对战斗有特殊影响
- **物品获取**：特定天气下更容易/更难发现某些物品

### 3. 天气预测

添加天气预报功能：

- 显示未来几天的天气预报
- 根据天气预报影响角色决策
- 特殊技能可以预测天气
